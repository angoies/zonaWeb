SASS¶

1. Introducción¶

¿Qué es Sass?

Sass (short for syntactically awesome style sheets) is a preprocessor scripting language that is interpreted or compiled into Cascading Style Sheets (CSS). SassScript is the scripting language itself.>

Por lo tanto lo que hagamos en Sass debe ser traducido a CSS. Tenemos dos posible sintaxis en Sass:

Sass consists of two syntaxes. The original syntax, called "the indented syntax," uses a syntax similar to Haml.[2] It uses indentation to separate code blocks and newline characters to separate rules. The newer syntax, SCSS (Sassy CSS), uses block formatting like that of CSS. It uses braces to denote code blocks and semicolons to separate rules within a block. The indented syntax and SCSS files are traditionally given the extensions .sass and .scss, respectively.

¿Qué añade a CSS? Viene a ofrecer:

  • Posibilidad de usar variables
  • Usar selectores anidados
  • Operadores
  • etc.

3. Ejemplos de uso¶

Se proponen alguno de los ejemplos propuestos en la guía de Sass: https://sass-lang.com/guide. Tiene el código de los ejemplos disponible en la propia guía (algunos se han modificado para simplificarlos o hacerlos más legibles).

3.1. Variables¶

Se puede paraemtriza el uso de medidas ,colores, etc.

Se muestra un ejemplo con el uso de una variable para el color. Cree un fichero de nombre estilos.scss

$primary-color: green;

p:nth-child(even) {
  color: $primary-color;
}

h1 {
  border-bottom: 2px solid $primary-color;
}

El fichero scss no es interpretable por el navegador, es necesario convertirlo antes a CSS. Basta que en VScode use la opción Paleta de Comandos / Live Sass: Compile Current Sass File.

Se crean dos archivos: estilos.css y estilocs.css.map. El primero es el que debe incluir en su fichero HTML.

El fichero estilos.css obtenido ya no tiene variables:

p:nth-child(even) {
  color: green;
}
h1 {
  border-bottom: 2px solid green;
}
/*# sourceMappingURL=estilos.css.map */

Nota: si desea puede activar el modo watch en el plugin (Live Sass: Watch mode) que detecta cambios en los ficheros .sass y automáticamente hace la compilación a CSS. Para detenerlo Live Sass: Stop watching

3.2. Selectores anidados¶

Ejemplo de una barra de navegación y se modifica para anidar los selectores:

/* Anidación */
nav {
    ul {
        padding: 0;
        list-style: none;
        border: 1px solid $primary-color;
        display: grid;
        grid-template-columns: repeat(5, 1fr);

        li {
            border: 1px solid $primary-color;
            text-align: center;

            a {
                display: block;
                padding: 6px;
                text-decoration: none;
            }
        }
    }
}

El resultado traducido sería:

/* Anidación */
nav ul {
    padding: 0;
    list-style: none;
    border: 1px solid green;
    display: grid;
    grid-template-columns: repeat(5, 1fr);
}

nav ul li {
    border: 1px solid green;
    text-align: center;
}

nav ul li a {
    display: block;
    padding: 6px;
    text-decoration: none;
}

3.3. mixins¶

A mixin lets you make groups of CSS declarations that you want to reuse throughout your site. It helps keep your Sass very DRY. You can even pass in values to make your mixin more flexible. Here's an example for theme

To create a mixin you use the @mixin directive and give it a name. We've named our mixin theme. We're also using the variable $theme inside the parentheses so we can pass in a theme of whatever we want. After you create your mixin, you can then use it as a CSS declaration starting with @include followed by the name of the mixiin.

Cree un mixin de nombre theme con un parámetro de nombre color (que tiene como valor por defecto silver):

/* mixin con variable */
@mixin theme($color: silver) {
    background: $color;
    box-shadow: 0 0 1px rgba($color, .25);
    color: #fff;
}

Para utilizarlo en ese mismo fichero se usa la directiva @include con el nombre del mixin.

.info {
    @include theme; /* usa tema por defecto, sivler */
}

.alert {
    @include theme($color: red);
}

.success {
    @include theme($color: #00dd00);
}

5. Anexos¶

5.1. Dart¶

Puede descargar dart-sass para Linux, descomprimir en el directorio /opt y añadir esa ruta al PATH. Puede seguir las instrucciones de estos enlaces:

Install Anywhere (Standalone)

You can install Sass on Windows, Mac, or Linux by downloading the package for your operating system from GitHub and adding it to your PATH. That’s all—there are no external dependencies and nothing else you need to install.

PATH:

  • Open the .bashrc file in your home directory (for example, /home/your-user-name/.bashrc) in a text editor.
  • Add export PATH="your-dir:$PATH" to the last line of the file, where your-dir is the directory you want to add.
  • Save the .bashrc file.
  • Restart your terminal.

Tras descomprimir en /opt y modificar el PATH:

alu@debian11:~$ ls -l /opt/dart-sass/
total 8
-rwxr-xr-x 1 root root  592 feb 19 10:23 sass
drwxr-xr-x 2 root root 4096 feb 19 10:23 src
alu@debian11:~$ echo $PATH
/opt/dart-sass/:/usr/local/bin:/usr/bin:/bin:/usr/local/games:/usr/games
alu@debian11:~$ 
alu@debian11:~$ sass --version
1.58.3
alu@debian11:~$

5.1.1. Utilización¶

El fichero scss no es interpretable en el navegador, es necesario convertirlo antes a CSS.

alu@debian11:~/bloque_CSS/t20_sass$ sass estilos.scss estilos.css
alu@debian11:~/bloque_CSS/t20_sass$

La segunda opción es que Sass traduzca cuando detecte cambios en el fichero con la opción --watch:

alu@debian11:~/bloque_CSS/t20_sass$ sass --watch estilos.scss estilos.css
Sass is watching for changes. Press Ctrl-C to stop.

[2023-02-19 10:47:02] Compiled estilos.scss to estilos.css.

También es posible aplicar la traducción sobre directorios completos:

You can watch and output to directories by using folder paths as your input and output, and separating them with a colon. In this example:

sass --watch app/sass:public/stylesheets

Sass would watch all files in the app/sass folder for changes, and compile CSS to the public/stylesheets folder.
