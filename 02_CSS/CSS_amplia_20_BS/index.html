Bootstrap - Introducción¶

1. Introducción¶

Lea esta introducción tomada de Bootstrap Ya (https://www.tutorialesprogramacionya.com/cssya/bootstrapya/detalleconcepto.php?punto=1&codigo=116&inicio=0)

Bootstrap es un framework (librerías de CSS) que nos facilita y estandariza el desarrollo de sitios web. A partir de la versión 3.x ha sido implementado pensando que se adapte tanto a las pantallas de equipos de escritorio como a móviles y tablets. Bootstrap ha sido desarrollada y es mantenida por la empresa Twitter y la ha liberado como un producto Open Source.

2. Primeros pasos¶

Acceda a la página Get started with Bootstrap https://getbootstrap.com/docs/5.2/getting-started/introduction/. Usaremos la última versión estable disponible. Y evitaremos versiones alpha o beta.

Para empezar bastará enlazar nuestra página HTML inicial con el fichero CDN que nos proponen añadiendo la etiqueta <link> en <head>

  ...
  <link 
     href="https://cdn.jsdelivr.net/npm/bootstrap@5.2.3/dist/css/bootstrap.min.css" 
     rel="stylesheet"
     crossorigin="anonymous"
     integrity="sha384-rbsA2VBKQhggwzxH7pPCaAqO46MgnOM80zW1RWuH61DGLwZJEdK2Kadq2F9CUG65">
  <title>Ejemplo Bootstrap</title>
</head>

Y en nuestra página web crear un contenedor con un <h1> y párrafos de relleno. Observe las clases utilizadas en el bloque div o en el elemento h1:

<body>
  <div class="container bg-light pt-3 mt-3">
    <h1 class="text-primary text-center">Ejemplo inicial BS5</h1>
    <p>Lorem ipsum dolor sit amet consectetur adipisicing elit. Libero laudantium commodi eos, officiis sint sunt
      perferendis impedit necessitatibus quasi nisi unde ullam, corrupti dolore et quos quidem dolores temporibus fugit.
    </p>
  </div>
</body>

Observe cómo simplemente incluyendo el fichero de estilos CSS de Bootstrap con link y usando clases en los elementos html:

  • ha cambiado la tipografía del documento
  • el contenedor tiene
  • margen superior (tp-3)
  • padding superior (pt-3)
  • color de fondo (bg-light)
  • el h1
  • está centrado y
  • tiene color primario.

3. Usando clases¶

3.1. Sobre colores¶

Bootstrap maneja colores por contextos: primary, secondary, success, info, warning, danger, light y dark.

Y estos contextos o colores se usa entre otras en las clases:

  1. text-<color>
  2. bg-<color>, text-bg-<color>
  <p class="text-primary">This text is important.</p>
  <p class="text-success">This text indicates success.</p>
  <p class="text-info">This text represents some information.</p>

Ejemplos y resumen rápido:

  • Color del texto: https://www.w3schools.com/bootstrap5/bootstrap_colors.php
  • Color de fondo: https://www.w3schools.com/bootstrap5/bootstrap_colors_bg.php

3.2. Propiedades de texto¶

Dispone de clases para alinear el texto:

<p class="text-start">Start aligned text on all viewport sizes.</p>
<p class="text-center">Center aligned text on all viewport sizes.</p>
<p class="text-end">End aligned text on all viewport sizes.</p>

O para modificar el font-style, font-weight, font-size, etc.

<p class="text-uppercase">Uppercased text.</p>
<p class="fs-3">.fs-3 text</p>
<p class="fw-bold">Bold text.</p>
<p class="fst-italic">Italic text.</p>

Más detalles en https://getbootstrap.com/docs/5.2/utilities/text/

3.3. Imágenes¶

Existen clases para redondear las esquinas de las imágenes, simular miniaturas (tumbnail) o redondear la imagen:

  • rounded-circle
  • rounded
  • img-tumbnail
  <p>The .rounded-circle class shapes the image to a circle:</p>            
  <img src="cinqueterre.jpg" class="rounded-circle" alt="Cinque Terre" width="304" height="236"> 
  <p>The .img-thumbnail class creates a thumbnail of the image:</p>            
  <img src="cinqueterre.jpg" class="img-thumbnail" alt="Cinque Terre" width="304" height="236">

Ejemplos de uso en https://www.w3schools.com/bootstrap5/bootstrap_images.php

3.4. Tablas¶

Permite poner bordes, alternar color de fondo en filas pares e impares, efecto hover, etc.

   <table class="table table-striped table-hover table-bordered border-primary">
      <thead>
        <tr class="text-bg-primary">
          <th scope="col">#</th>
          ...

Ejemplos de uso en https://getbootstrap.com/docs/5.2/content/tables/#overview

3.5. Botones¶

Bootstrap proporciona diferentes estilos de botones:

<button type="button" class="btn btn-primary">Primary</button>
<button type="button" class="btn btn-outline-danger">Danger</button>
<a href="#" class="btn btn-success">Link Button</a>
<button type="button" class="btn btn-primary btn-lg">Large</button>
<button type="button" class="btn btn-primary">Default</button>
<button type="button" class="btn btn-primary btn-sm">Small</button>

Incluso puede presentar un enlace en forma de botón:

  <h2>Button Elements</h2>
  <a href="#" class="btn btn-success">Link Button</a>

Ejemplos en https://www.w3schools.com/bootstrap5/bootstrap_buttons.php

3.6. Iconos¶

Para incorporar los iconos que Bootstrap proporciona debe seguir las indicaciones de https://icons.getbootstrap.com/#install:

  1. Usar un CDN con <link> al fichero CSS con las definiciones de los iconos

    <link rel="stylesheet" 
  href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">

  2. Usar Icon font eiInsertar el icono en el código HTML usando el elemento <i> sin contenido y aplicándole la clase del icono:

    <!-- Ejemplo de icono antes de h2 -->
<h2> <i class="bi-alarm"></i> Iconos</h2>
<!-- Ejemplo de icono en botón -->
<button type="button" class="btn btn-primary">
  <i class="bi-arrow-90deg-left"></i> Button
</button>

Más información en https://icons.getbootstrap.com/#icon-font.

3.7. Formularios¶

Tiene detalles y ejemplos de uso de BootStrap con formularios en este enlace: https://www.w3schools.com/bootstrap5/bootstrap_forms.php

Se le añaden las clases

  • form-label a las etiquetas.
  • form-control a los inputs.

Y se pueden a su vez especifiar el tipo de input con class="form-check-input", class="form-select", etc.

Además nos pueden interesar posibilidades como:

  • Etiquetas flotantes: https://www.w3schools.com/bootstrap5/bootstrap_form_floating_labels.php
  • Decorar la validación de los campos del formulario: https://www.w3schools.com/bootstrap5/bootstrap_form_validation.php

4. Layout¶

Tiene dos tutoriales a seguir para este apartado:

  • Documentación oficial de BS5: https://getbootstrap.com/docs/5.2/layout/grid/
  • W3schools Grid: https://www.w3schools.com/bootstrap5/bootstrap_grid_system.php

4.1. Bootstrap Grid System¶

Si hace un layout no adaptativo basta con saber que debe organizar el contenido en filas (class="row"), y que cada fila tiene por defecto doce columnas. Para especificar que un elemento es una columna y el tamaño de esa columna se usa la notación class="col-X" (siendo X el tamaño sobre 12). Si no se especifican los tamaños se reparte para ocupar toda la fila.

4.2. Layout RWD¶

BootStrap tiene definidos puntos de ruptura para hacer diseños adaptativos (RWD).

Si usamos la clase col-X se entiende que ese es el layout para todos los anchos de pantalla empezando por el extra-small.

Haga una pequeña modificación sobre el ejemplo anterior: sustituir las clases col-X por col-sm-X. Ahora para pantallas de ancho mayor a 576px se mantiene el diseño previo pero para menores, al no estar definido el comportamiento, se pasa a un diseño apilado (diseño por defecto).
