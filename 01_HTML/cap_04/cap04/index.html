    2. Extensiones tipo Live Server en VsCode¶

    Se recomienda iniciar VSCode abriendo una carpeta o directorio, y esta se convierte en la raíz del proyecto.

    Al usar la extensión Live Server (o similares) se inicia un servidor web de desarrollo. Dicho servidor web usa como raíz del sitio web la carpeta que se usó al iniciar el editor. Esto es importante a la hora de especificar rutas relativas a la raíz.

    Al iniciar VSCode..

    Si inicia VS Code sin indicar directorio o con un fichero (en vez de una carpeta), al intentar usar este tipo de complementos mostrará un error y le indicará que es necesario abrir una carpeta (folder).

    3. El Atributo download¶

    Si en un enlace añade el atributo download

    <a href="/web/grafica.png" download>
    Tomado de MDN:

    Este atributo indica descargar a los navegadores una URL en lugar de navegar hacia ella: el usuario será dirigido para guardarla como un archivo local.

    Si el atributo tiene un valor, éste se utilizará como nombre de archivo por defecto en el mensaje Guardar que se abre cuando el usuario hace clic en el enlace (sin embargo, el usuario puede cambiar el nombre antes de guardar el archivo).

    4. El atributo target¶

    A un enlace se le puede añadir el atributo target:

    <a href="/" target="_blank">The home page will open in another tab.</a>

    Los valores posibles de este atributo target son:

    • target="_blank": abre siempre el enlace en una nueva pestaña o ventana del navegador
    • target="_self": es la opción por defecto, muestra el contenido del enlace en la misma ventana
    • target="nombre": si se indica un nombre se abre el contenido en una pestaña con ese nombre. Si hay otros enlaces con ese nombre se usará dicha pestaña para mostrar el contenido.

    valores de blank

    Frames deprecated; only use _blank¶

    The only currently relevant value of target is _blank. The other values of target were used to specify specific frames. However, frames have been deprecated in HTML5.

    Default target¶

    If no target is specified, the link will open in the current context, unless the user or browser specifies otherwise. Read more: https://html.com/attributes/a-target/#ixzz7g581fqxs
