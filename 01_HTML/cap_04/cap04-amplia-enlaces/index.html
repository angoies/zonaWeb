Cap 04 Ampliación Enlaces¶

1. Usar una imagen como enlace¶

Basta con "envolver" la imagen con el elemento a:

<a href="http://acme.org">
  <img src="logo.png" alt="logo empresa Acme" width="32" height="32" >
</a>

3. Extensiones tipo Live Server en VsCode¶

En general se recomienda iniciar VSCode abriendo una carpeta o directorio, y esta se convierte en la raíz de nuestro proyecto.

Al usar la extensión Live Server o similares se inicia un servidor web de desarrollo. Dicho servidor web usa como raíz del sitio web dicha carpetala carpeta. Esto es importante a la hora de especificar rutas relativas a la raíz. Si inicia VS Code con un fichero en vez de una carpeta, al intentar usar este tipo de complementos mostrará un error y le indicará que es necesario abrir una carpeta (folder).

4. El Atributo download¶

Tomado de MDN:

Este atributo indica descargar a los navegadores una URL en lugar de navegar hacia ella, por lo que el usuario será dirigido para salvarla como un archivo local. Si el atributo tiene un valor, éste se utilizará como nombre de archivo por defecto en el mensaje Guardar que se abre cuando el usuario hace clic en el enlace (sin embargo, el usuario puede cambiar el nombre antes de guardar el archivo).

Ejemplo de su uso:

<a href="/images/myw3schoolsimage.jpg" download>

5. El atributo target¶

Los valores posibles del atributo target son:

  • target="_blank": abre siempre el enlace en una nueva pestaña o ventana del navegador
  • target="_self": es la opción por defecto, muestra el contenido del enlace en la misma ventana
  • target="nombre": si se indica un nombre se abre el contenido en una pestaña con ese nombre. Si hay otros enlaces con ese nombre se usará dicha pestaña para mostrar el contenido.

Y si usara frames hay otras opciones, pero los framesets están ya obsoletos (deprecated).

Frames deprecated; only use _blank¶

The only currently relevant value of target is _blank. The other values of target were used to specify specific frames. However, frames have been deprecated in HTML5.

Default target¶

If no target is specified, the link will open in the current context, unless the user or browser specifies otherwise. Read more: https://html.com/attributes/a-target/#ixzz7g581fqxs

Aviso: si usa "_blank" como target debería leer algunas cuestiones de seguridad:

  • La vulnerabilidad target=»_blank» en WordPress
  • Don’t Use target=”_Blank”
