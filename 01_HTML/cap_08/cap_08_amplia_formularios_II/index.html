Formularios HTML II¶

Tiene el código de estos elementos en los ficheros de ejemplos.

1. Range¶

El Input de tipo range es similar a number pero proporcionando un control gráfico:

<label id="volumen"> volumen </label> <br>
<input type="range" name="volumen" id="volumen" min="0" max="10" step="1" value="5">

2. Color¶

El input de tipo color muestra un selector para elegir color. Se envía el código hexadecimal que le corresponde:

<label id="colorFondo"> Color de fondo </label> <br>
<input type="color" name="colorFondo" id="colorFondo" value="#ffff00">

3. Patrones¶

El atributo pattern se le puede añadir a un input de tipo texto y restringe los posibles valores de la entrada.

En este ejemplo se fuerza a un formato para un DNI: 9 dígitos seguidos de una letra mayúscula entre A y Z. Estudiará patrones con más detenimiento en otros módulos.

<label id="dni"> NIF </label> <br>
<input type="text" name="dni" pattern="[0-9]{8}[A-Z]" id="dni">

Enlace sobre expresiones regulares

4. datalist¶

El elemento datalist y su atributo asociado list sirven para presentar al usuario una lista de sugerencias de valores (no limita, se puede enviar otro valor no incluido en la lista).

El input y la datalist se relaciona con el atributo list en el input y el id en el datalist.

  <label for="from"> Origen: </label> <br> 
  <input name="from" type="text" list="city" id="from">
  <datalist id="city">   
    <option value="Adelaide">Adelaide
    <option>Beijing
    <option>Bangkok
    <option>Hanoi
    <option>Hong Kong
  </datalist>

5. search¶

El input de tipo search es similar al de texto. Algunos agentes de usuario cambian la forma de mostrarlo, o muestran entradas anteriores.

<label id="buscar"> NIF </label> <br>
<input type="search" name="buscar" id="buscar" >

6. Tipo file y atributo accept¶

El atributo accept toma como valor una lista separada por comas de uno o más tipos de archivos, o especificadores de tipo de archivo únicos, que describen qué tipos de archivo permitir.

Ejemplo de uso:

<input type="file" name="resumen"
  accept=".doc,.docx,application/msword" />
<input type="file" name="soundFile" accept="audio/*" />
<input type="file" name="videoFile" accept="video/*" />
<input type="file" name="imageFile" accept="image/*" />

7. number y decimales¶

En el tipo number además del valor any puede especificar el salto en los decimales, por ejemplo step="0.01". Esto permite hasta dos dígitos en la parte decimal con incrementos de una centésima.

<input type="number" name="precio" step="0.01" min="0"/>

8. Varios¶

  • El atributo autofocus es un atributo del tipo lógico. Su existencia en un input indica que dicha entrada deberá obtener el foco cuando la página se muestra.
  • No todos los navegadores soportan siempre todos los inputs, . Por ejemplo, los inputs date, time o color no se interpretan correctamente en Internet Explorer. En estos caso de inputs no conocido se interpretan como de tipo text, que es el valor por defecto de un input.
  • Existen otros inputs relacionados con date y time: datetime, week, month, etc.
