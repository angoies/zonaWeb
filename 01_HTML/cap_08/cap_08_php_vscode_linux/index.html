Server PHP y linux¶

1. Instalar server PHP¶

Puede utilizar el servidor de pruebas que incorpora el paquete PHP (comando php -S).

$ php -S localhost:8000
[Wed Jun 25 20:23:41 2025] PHP 8.2.28 Development Server (http://localhost:8000) started
...

Si no estuviese instalado basta con instalar el paquete php-cli:

$ sudo apt update
$ sudo apt install php-cli
...
$ php --version
PHP 8.2.7 (cli) (built: Jun  9 2023 19:37:27)
Copyright (c) The PHP Group
...
$

2. Servidor PHP en línea de comandos¶

Para probarlo crear en el directorio del proyecto el fichero index.php:

index.php
<?php
  phpinfo();
?>

Lanzar el servidor de pruebas PHP con el comando php -S <IP>:<puerto>

$ php -S localhost:5000
[Thu Oct 20 12:08:04 2022] PHP 7.4.30 Development Server (http://localhost:5000) started

Abrir el navegador con la URLhttp://localhost:5000 (por ejemplo desde otra terminal):

firefox http://localhost:5000 &

En el navegador se muestra una tabla con información sobre PHP. Y en la consola del servidor le aparece el log con las peticiones que se realizan:

$ php -S localhost:5000
[Thu Oct 20 12:08:04 2022] PHP 7.4.30 Development Server (http://localhost:5000) started
[Thu Oct 20 12:17:23 2022] [::1]:47404 Accepted
[Thu Oct 20 12:17:23 2022] [::1]:47404 [200]: (null) /
[Thu Oct 20 12:17:23 2022] [::1]:47404 Closing

Tenga en cuenta que por defecto la raíz del sitio web será el directorio desde dónde se ha iniciado el servidor PHP.

3. Plugin en VSCode¶

Una vez instalado php-cli puede instalar el plugin PHP Server de brapifra que se basa en el servidor PHP instalado en el sistema. Tenga en cuenta que no es un "live server"

Para lanzar el servidor debe usar la opción "PHP Server: Serve Project"
