    Server Python en linux¶

    En este ejemplo se usa Python y el framework Flask para recibir la petición de un formulario.

    1. Instalar Flask¶

    Instalar Flask (en entorno virtual)

    python -m venv venv
source venv/bin/activate
pip install flask

    2. El servidor¶

    Este sería el código del servidor:

    servidor_flask.py
    from flask import Flask, request

app = Flask(__name__)

@app.route('/', methods=['GET', 'POST'])
def procesar_formulario():

    if request.method == 'POST':
        # Procesar datos enviados por POST 
        print("\n--- PETICIÓN POST RECIBIDA ---")
        for key, value in request.form.items():
            print(f"Campo [{key}] = {value}")
        print("-" * 31 + "\n")
        return "Datos POST recibidos correctamente."

    else:
        # Procesar datos enviados por GET
        print("\n--- PETICIÓN GET RECIBIDA ---")
        for key, value in request.args.items():
            print(f"Parámetro [{key}] = {value}")
        print("-" * 30 + "\n")
        return "Datos GET recibidos correctamente."

if __name__ == '__main__':
    app.run(host='0.00.0', port=5000, debug=True)

    3. Lanzar servidor¶

    python servidor_flask.py
