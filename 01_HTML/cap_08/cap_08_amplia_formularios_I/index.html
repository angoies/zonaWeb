    Amplia Formularios HTML I¶

    1. Introducción¶

    Este documento incluye ejemplos de algunos de los nuevos elementos y atributos para formularios que añade HTML.

    • Nuevos tipos de input:
    • email
    • date
    • time
    • tel
    • url

    • number

    • Nuevos atributos:

    • placeholder
    • required
    • novalidate
    • max, min, step
    • multiple
    • autofocus

    2. Nuevos tipos de inputs¶

    2.1. email¶

    El input de tipo email comprueba que el valor que se introduce sigue la sintaxis de un correo electrónico.

     <label id="correo"> Correo </label> <br>v
 <input type="email" name="correo" id="correo" placeholder="Correo corporativo">

    2.2. url¶

    El input de tipo url comprueba que el valor que se introduce sigue la sintaxis de una URL.

    <label id="url"> Página Web </label> <br>
<input type="url" name="url" id="url" placeholder="URL destino">

    2.3. tel¶

    El input de tipo tel NO comprueba que el valor que se introduce sigue la sintaxis de un teléfono, pero podría activar el teclado numérico en un móvil. Si desea controlar el valor introducido puede usar un patrón (pattern)

     <label id="tel"> Teléfono de empresa </label> <br>
 <input type="tel" name="tel" id="tel" placeholder="teléfono">

    2.4. number¶

    El input de tipo number permite comprobar si es el valor introducido es un número válido. Además podría indicar un valor mínimo (atributo min), un máximo (max) e incluso el valor de incremento (step) que por defecto toma el valor 1.

     <label id="cantidad"> Cantidad </label> <br>
 <input type="number" name="cantidad" id="cantidad" min="2" max="10" step="2" value="6">

    Si desea números con decimales el atributo step debe tomar el valor any

     <label id="precio"> Precio </label> <br>
 <input type="number" name="precio" id="precio" step="any">

    Además del valor any puede especificar el salto en los decimales, por ejemplo step="0.01". Esto permite hasta dos dígitos en la parte decimal con incrementos de una centésima.

    <input type="number" name="precio" step="0.01" min="0"/>

    2.5. date y time¶

    El input de tipo date comprueba si la fecha es correcta, y el navegador facilita un calendario para seleccionar la fecha.

     <label id="fechaCompra"> Fecha de compra </label> <br>
 <input type="date" name="fechaCompra" id="fechaCompra">

    El input de tipo time comprueba si la hora es correcta, y facilita un control para seleccionar.

     <label id="horaEntrada"> Hora de entrada </label> <br>
 <input type="time" name="horaEntrada" id="horaEntrada" value="15:00">

    más de time

    Existen otros inputs relacionados con date y time: datetime, week, month, etc.

    3. Atributos¶

    • El atributo placeholder en un input es una pequeña ayuda o descripción sobre el valor esperado en dicha entrada del formulario. No confundir con el valor por defecto, que se especifica con value.
    • El atributo required en un input hace que el formulario no se envíe si no se introducen datos en ese input .
    • El atributo novalidate en el elemento form desactiva la validación local de los input de tipo date, mail, url, etc.
    • El atributo multiple permite en algunso inputs (pe. file o email) asociar varios elementos. En el tipo file el selector permite selección multiple, y en el tipo email admite varios valores separados por comas.
    • El atributo autofocus es un atributo del tipo lógico. Su existencia en un input indica que dicha entrada deberá obtener el foco cuando la página se muestra.
