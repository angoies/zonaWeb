    Varios Ampliación¶

    En este apartado se añaden algunos elementos que no aparecen en los apuntes:

    • Elemento figure
    • Elemento audio
    • Elemento video
    • Elemento details

    1. El elemento figure¶

    El elemento HTML <figure> representa contenido independiente, a menudo con un título. Si bien se relaciona con el flujo principal, su posición es independiente de éste. Por lo general, se trata de una imagen, una ilustración, un diagrama, un fragmento de código, o un esquema al que se hace referencia en el texto principal, pero que se puede mover a otra página o a un apéndice sin que afecte al flujo principal.

    Ejemplo de figure con imagen:

    <figure>
  <img src="img_pulpit.jpg" alt="The Pulpit Rock" width="304" height="228">
  <figcaption>Fig1. - A view of the pulpit rock.</figcaption>
</figure>

    Ejemplo de figure con una cita:

    <figure>
 <blockquote>"El ordenador nació para resolver problemas que antes no existían"<blockquote>
 <figcaption>Cita famosa  de <cite>Bill Gates</cite></figcaption>
</figure>

    Tiene más información en este enlace, donde se muestran figuras y distintas posibilidades.

    2. El elemento Audio¶

    Nota: Antes de HTML 5 el contenido multimedia se reproducía mediante extensiones (plugins: realplayer, flash player...).

    <audio controls>
 <source src="horse.ogg" type="audio/ogg">
 <source src="horse.mp3" type="audio/mpeg">
 Your browser does not support the audio element.
</audio>

    Tenga en cuenta:

    • Varios elementos <source> se enlazan a diferentes ficheros de audio. El navegador usará el primero que encuentre con un formato que pueda reproducir.
    • El atributo controls añade controles de reproducción como pausa, volumen, etc.
    • El texto delimitado por <audio> y </audio> se muestra si el navegador no soporta el elemento <audio>.

    Direcciones de dos ficheros de audio para hacer pruebas:

    • https://www.w3schools.com/html/horse.ogg
    • https://www.w3schools.com/html/horse.mp3

    3. El elemento video¶

    Su uso es similar al del elemento audio visto previamente:

    <video width="320" height="240" controls>
 <source src="movie.mp4" type="video/mp4">
 <source src="movie.ogg" type="video/ogg">
 Your browser does not support the video tag.
</video>

    Direcciones de dos ficheros de video para pruebas:

    • https://www.w3schools.com/html/mov_bbb.mp4
    • https://www.w3schools.com/html/mov_bbb.ogg

    Tenga en cuenta:

    • Varios elementos <source> se enlazan a diferentes ficheros de video. El navegador usará el primero que encuentre con un formato que pueda reproducir.
    • El atributo controls añade controles de video como pausa, volumen, etc.

    • El texto delimitado por <video> y </video> se muestra si el navegador no soporta el elemento <video>.

    • Es recomendable incluir en este elemento los atributos width y height para que el navegador conozca el tamaño del vídeo y reserve espacio en pantalla mientras se carga.

    4. Elemento details (y summary)¶

    El elemento HTML <details> es usado como un widget de revelación a través del cual el usuario puede obtener información adicional si está en estado "abierto". Cerrado muestra el contenido del elemento summary. Se representa con un triángulo que gira del estado cerrado al estado abierto.

    <details>
  <summary>Copyright 1999-2014.</summary>
  <p> - by Refsnes Data. All Rights Reserved.</p>
  <p>All content and graphics on this web site are 
   the property of the company Refsnes Data.</p>
</details>
