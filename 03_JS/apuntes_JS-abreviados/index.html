JavaScript Abreviado¶

1. Introducción¶

Este documento sólo pretende dar una introducción rápida a JavaScript.

  • En la carpeta 00_iniciales tiene ejemplos básicos de inclusión de código javascript en una página HTML.
  • En la carpeta 01_formulario tiene ejemplos de validación de formulario con JavaScript.
  • En la carpeta 02_DOM tiene ejemplos del uso del modelo DOM para acceder a los elementos HTML, su contenidos, sus atributos, estilos ,etc.
  • En la carpeta 03_eventos tiene ejemplos del uso de eventos.
  • En la carpeta 00_hora tiene un ejemplo del uso de Javascript para modificar estilos o contenidos en función de la hora del día.

2. Ejemplos básicos¶

2.1. Modificar contenido¶

ejemplo01.html
<h2>What Can JavaScript Do?</h2>

<p id="demo">JavaScript <strong>can change</strong> HTML content.</p>

<button type="button" 
  onclick='document.getElementById("demo").innerHTML = "Hello JS!"'>
    Click Me!
</button>

2.2. Modificar atributo¶

ejemplo02.html
<button 
        onclick="document.getElementById('myImage').src='figuras/pic_bulbon.gif'">
        Turn on the light
</button>

<img id="myImage" src="figuras/pic_bulboff.gif" style="width:100px" alt="bombilla">

<button 
    onclick="document.getElementById('myImage').src='figuras/pic_bulboff.gif'">
    Turn off the light
</button>

2.3. Modificar estilo CSS¶

ejemplo04.html
<button
    type="button" 
    onclick="document.getElementById('demo').style.fontSize='35px'">
    Click Me!
</button>
