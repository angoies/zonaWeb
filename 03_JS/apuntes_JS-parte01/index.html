Introducción JavaScript 01¶

1. Referencias¶

  • JavaScript Tutorial W3Schools: https://www.w3schools.com/js/default.asp
  • Introducción a JavaScript en Uniwebsidad ahora en archive.org
  • Eloquent JavaScript: https://eloquentjs-es.thedojo.mx/
  • Manual JavaScript : https://desarrolloweb.com/home/javascript

2. Entorno de trabajo¶

  • En este bloque se usa una máquina virtual con Linux y VSCode como editor.
  • Es posible que se añadan a VSCode algunos plugins para JavaScript.

3. Introducción¶

Sobre la historia de JavaScript y ECMAScript puede ver el apartado Historia de esta página: https://desarrolloweb.com/home/javascript

Y para tener una primera aproximación al uso de JavaScript puede ver los ejemplos de esta página https://www.w3schools.com/js/js_intro.asp. Entre ellos JavaScript le permite:

  • reaccionar a eventos.
  • modificar el contenido de la página HTML: cambiar el contenido de un elemento, añadir nuevos elementos o borrar elementos.
  • modificar los estilos CSS que se aplican.
  • verificar valores de entradas en formularios.
  • o hacer cálculos, presentar resultados, etc,

4. Sintaxis básica JavaScript¶

4.1. Cómo incluir el código¶

Recuerde que el código JavaScript se interpreta y ejecuta en el navegador. Y para ello debe conocer cómo incluir el código javascript en la página HTML.

Puede incluir el código en el head y en el body. Y puede hacerlo incluyendo directamente el código o incluyendo un enlace a un fichero con el código javascript.

Tiene los detalles es estos enlaces:

  • W3schools: JavaScript Where To
  • Uniwebsidad: Cómo incluir JavaScript en documentos XHTML

Tiene ejemplos de cómo hacerlo en los ficheros ejemplo001.html y ejemplo002.html. Un extracto de los mismos:

ejemplo01.html
  <h1>Ejemplos inclusión codigo js</h1>
  <script>
      // comentario en script JS
      alert("Hola desde body fichero HTML");
  </script>
  <script src="ejemplo001.js"></script>

O un ejemplo de fichero con funciones en head

  ...
  <title>Ejemplo 02</title>
  <script src="ejemplo002.js"></script>
</head>
<body>

Tenga en cuenta que el lugar donde incluya el código puede ser importante ya que si se ejecuta código que tiene que acceder a elementosa HTML y estos todavía no se han cargado el resultado no es el esperado.

4.2. Comentarios JavaScript¶

Los comentarios en JavaScript pueden ser de de dos tipos:

  • comentarios de línea
  • comentarios de bloque
let media = 0;   // media de todo el grupo

/*  Pendiente aclarar el cálculo de las medias
  por trimestres o anuales */

4.3. Variables y sus tipos¶

Para una introducción al uso de variables y sus tipos debe consultar:

  • Apartados de W3Schools
  • JavaScript Variables
  • JavaScript Data Types
  • o en Uniwebsidad (web.archive.org):
  • 3.1 Variables
  • 3.2. Tipos de variables

Resumiendo, se definen las variables con let (evitar el uso de var). Si no se deben modificar usar const. Procurar definirlas agrupadas al inicio del script o del bloque. Y para ver su tipo se puede usar typeof

Tipos más frecuentes:

  • numéricas (Number)
  • cadenas de texto (String)
  • lógicas o booleanas (Boolean) que toman los valores true y false
  • Y los tipos especiales:
  • undefined: es el tipo de datos de una variable que no ha sido inicializada, no se le ha asignado ningún valor
  • null: es un valor especial que asigna el programador e indica que la varaible tiene un valor desconocido o vacío.

Ejemplos de uso:

ejemplo003.js
// Numbers:
let length = 16;
let weight = 7.5;

console.log(typeof(weight))

// Strings:
let color = "Yellow";
let lastName = "Johnson";

// Booleans
let x = true;
let y = false;

// undefined
let z;
console.log("z: ", z)
console.log(typeof z)

// null
let w = null;
console.log("w: ", w)
console.log(typeof w) // object

Más adelante se presentarán otros tipos:

  • arrays
  • objetos
  • fechas

Tiene el código de estos ejemplos en ejemplo003.html y ejemplo003.js.

4.4. Operadores¶

Consultar:

  • W3Schools: JavaScript Operators
  • Uniwebsidad: 3.3. Operadores

4.4.1. Operador de asignación¶

Este operador se utiliza para guardar un valor específico en una variable. También se expresa indicando que se crea un "vinculación" entre la variable y el valor asignado:

let edadA = 7;
let edadB = 8;
let media = 0;

Después de asignar se puede usar el valor de la variable en expresiones o modificar el valor de la asignación:

let suma = edadA + edadB;
media = suma/2;

Si se encuentra una asignación como variable = variable + expresión; se puede expresar tambien usando el operador += y quedaría variable += expresión;

let edadC = 24;

// a) forma "normal"
suma = suma + edadC;  

// b) forma compacta
suma += edadC;

Se puede usar esta notación con otros operadores como la resta, producto, etc. Tiene estos ejemplos ampliados en ejemplo004.html y ejemplo004.js.

4.4.2. Operadores matemáticos¶

  • + Suma
  • - Resta
  • * Multiplica
  • ** Potencia
  • / Divide
  • % Módulo (resto)
  • ++ Incrementa
  • -- Decrementa

4.4.3. Operadores lógicos¶

  • && Y lógico (AND)
  • || O lógico (OR)
  • ! NO lógico (NOT)

4.4.4. Operadores relacionales¶

Los más habituales:

  • == compara si los valores son iguales
  • != distinto que
  • > mayor que
  • < menor que
  • >= mayor o igual que
  • <= menor o igual que

También existe el operador ternario ? que asigna un valor entre dos posibilidades al evaluar una condición:

// let variable = (condición) ? valor1 : valor2; 
let puedeJugar = (edad < 18) ? false :true;

Puede ocurrir que al hacer la comparación los valores sean iguales pero no los tipos. Por esa razón existe estos dos operadores:

  • === compara si los valores y los tipos son iguales
  • !== si son distintos los valores o son distintos los tipos

4.4.5. Operadores de string¶

  • + concatena dos cadenas
  • += concatena y asigna

Tenga en cuenta que si añade un número a un string el resultado será de tipo string:

let a = 5
let b = "6"
let suma = a + b;
// => suma = "56"

4.5. Mostrando resultados¶

Hasta ahora se han mostrado los resultados con la función console.log(). Pero tenemos más posibilidades.

En este enlace se nos muestran otras posibilidades: https://www.w3schools.com/js/js_output.asp

  • Escribir en la salida HTML usando document.write().
  • Escribir en una caja de alerta usando window.alert().
  • Escribir en la consola del navegador usando console.log().

Existe otra posibilidad: mostrar los resultados en el documento HTML usando el modelo DOM y sus métodos.

<p id="demo"></p> <!-- para resultado -->
<script>
  let edadA = 23;
  let edadB = 26;
  let res = (edadA + edadB)/2;

  // modifica el contenido del elemento con id="demo"
  document.getElementById("demo").innerHTML = res;
</script>

Tiene otro ejemplo más completo en en ejemplo009.html y ejemplo009.js.

5. Entrada de datos: confirm y prompt¶

Tiene ejemplos de su uso en este enlace: JavaScript Popup Boxes

En resumen:

  • confirm devuelve true o false y permite bifurcar el código en función de lo que pulse el usuario.
  • prompt solicita un valor al usuario. Devuelve:
  • el valor introducido si el usuario pulsa OK.
  • null si el usuario pulsa Cancel.

Tenga en cuenta que prompt devuelve el valor introducido como una cadena de caracteres. Tiene ejemplos de su uso en ejemplo010.html y ejemplo010.js.
